# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, criticise ideas and not people, and keep discussions about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests or any other project space.

To report a problem, contact the maintainer, Abdurrahim Arif Aşıroğlu, at aaasiroglu@outlook.com. Reports are handled confidentially.
